# Square macro key artwork

- macro-idle.png and macro-pressed.png: 1254 x 1254 RGBA, actual transparent exterior.
- Generated from the approved circular button material reference with imagegen; pressed version edited from idle to preserve silhouette and alignment.
- Blank faces: symbols and labels are live UI layers. The same two files serve all four macro keys.
- Durable copies are also in design/production-assets-v1 and the phone mockup public/assets/murmr folder.
- Preview layout: four 72px square touch targets at the corners of a 282px-high control cluster; original 250px microphone button remains centered. Its circular hit area avoids consuming the corners.
- ENTER, TAB, ESC, PASTE are example assignments only. This mockup reports taps in the transcript and flashes pressed artwork; no host key events, clipboard access, or assignment persistence.
- Macro keys are disabled while disconnected, listening, finishing, typing, or awaiting microphone permission.
- Browser verified all four demo actions and disabled controls during finishing. Build and runtime integrity passed. Android app not modified.
